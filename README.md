# House Price Prediction

A Machine Learning web application that predicts house prices based on different house features.

##  Project Description

This project uses a Machine Learning model to predict the price of a house based on:

- Area (sqft)
- Number of Bedrooms
- Number of Bathrooms
- Number of Floors
- Location
- House Condition
- Garage
- Age

##  Technologies Used

- Python
- Machine Learning
- Jupyter Notebook
- FastAPI
- React
- TypeScript
- CSS

## Project Structure

- `backend/` → Backend API and Machine Learning model
- `frontend/` → React frontend application
- `House Price Prediction Dataset.csv` → Dataset
- `Untitled.ipynb` → Machine Learning model training
- `house_price.pkl` → Trained Machine Learning model

## How It Works

1. The user enters the house details.
2. The frontend sends the data to the backend.
3. The Machine Learning model processes the input.
4. The predicted house price is returned and displayed to the user.
